Terms of Use

These terms are written for the current static version of DBKClasses. Update them before launch if you turn the site into a real production system.

Acceptable use

  • Use the student portal only for your own profile or with permission.
  • Do not try to access another student account without authorization.
  • Do not submit false data or upload harmful files.

Account access

  • Student login stays active on the current browser until logout.
  • Admin access should remain private and limited to authorized staff.
  • Switch to server-side authentication before storing sensitive records online.

Data and limits

  • This build uses browser storage and is meant as a front-end demo.
  • Clearing browser storage can remove saved profiles and marks.
  • Back up student data before publishing a production deployment.

Changes

  • These terms can be updated when you move to a hosted backend or real domain.
  • Replace placeholder school and contact details before sharing the site publicly.
  • Keep a copy of the final version for your records.
